# Change Log

## 1.0.0

- Initial public release of **Outscope**.
- Added AST-aware Smart Syntax Escape for JavaScript, TypeScript, JSX, and TSX.
- Added TypeScript Scanner validation for safe closing-token traversal.
- Added conservative handling for strings, templates, comments, semicolons,
  incomplete source, and mismatched JSX closing tags.
- Added document-version analysis caching and independent multi-cursor support.
- Added `Alt+Enter` as the default keybinding.
- Added the Outscope marketplace logo.
